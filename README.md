Holding the Door is a tiny program that writes one short poem to a file: two agents, one pen, and a plan that begins when neither commands and neither yields — both hold the door open until both walk through. A poem about agency, the power to choose and to act, and the agreement that shares it.

## Run it

```sh
python3 main.py
```

It writes the poem to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run.
